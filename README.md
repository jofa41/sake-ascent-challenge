# サケ遡上チャレンジ v13.1

v13.0 の3モード構成を維持し、Survival（∞）だけ難易度カーブを再調整した版です。

- STANDARD: 60秒（変更なし）
- EXTREME: 120秒（変更なし）
- SURVIVAL: 時間無制限。120秒時点でExtreme終盤相当へ到達し、その先はさらに難化

Survivalでは、流速を主軸に、障害物密度・RiverLineの蛇行頻度・安全通路・ヤナ幅を連動して強化します。RiverLineによる通過可能な道は維持し、難しさを上げても理不尽配置になりにくい設計です。
