# サケ遡上チャレンジ v11 RiverLine試作版

Project S-04の第一段階です。合格済みStandard 60秒を土台に、ModeConfigとRiverLineを導入しました。

## 今回の変更
- 時間・速度・出現間隔・ヤナ設定を `MODE_CONFIG` に集約
- 見えないRiverLineを緩やかに蛇行
- 岩・流木はRiverLineの安全通路を塞がない位置へ生成
- ヤナの目をRiverLine上へ統一
- 光る泡は安全通路付近、一部は小さな寄り道位置へ生成

## 変更していないもの
- 操作方法
- 魚の見た目とサイズ
- 60秒、3ライフ、距離計算
- ヤナ前の新規障害物停止
- ボーナスと演出

実機確認では「理不尽さが減ったか」「一本道すぎないか」「以前より気持ちよいか」を確認してください。
